# iPad 驱动登记修复与实机验证

2026-09-26，Windows x64，Apple USB 538.0.0.0 / libusb-win32 1.4.0.2。

## 修复

当前 iPad（PID 12AB）未登记 filter，另一台已断开的设备（PID 12A8）保留登记。
共享驱动处于 Stopped。安装器因离线登记记录提前拒绝继续，无法执行后面的驱动启动步骤。

移除新增设备路径中的提前拒绝，保留绑定范围、文件哈希、缺失文件检查，
由原有启动步骤加载驱动并确认 Running 后再登记选中设备。
驱动启动失败或启动后仍未运行时，不执行 filter 安装。
已登记设备原有检查逻辑保持不变。

修复已部署至 D:/GreenSoftware/ZLUsbAudioBridge/DriverInstallKit-x64-1.4.0.2/DriverKit.Common.ps1，
原文件在同目录备份为 DriverKit.Common.ps1.before-ipad-fix-20260926-192528.bak。
仓库 dist/DriverInstallKit-x64-1.4.0.2.zip 已重新打包。
实机登记成功，驱动 Running，安装器检查 READY。登记后需物理拔插一次生效。

## 验证

- Windows PowerShell 5.1：24 项多设备模拟测试、12 项安装守卫检查通过。
- 新增覆盖：旧设备离线且驱动停止、新设备登记前启动、启动报错、启动后仍停止。
- 20 秒静音采集：822 音频包，837696 已渲染帧；视频包、欠载、缺失帧、丢帧均为 0。
- 15 秒保守停止模式复测：591 音频包，601536 已渲染帧；视频包、欠载、缺失帧、丢帧均为 0。

## 未通过项

两次采集都在停止后的 USB 普通配置恢复检查中超时，最终 state=5、进程退出码 1。
因此不能将报告描述为端到端全部通过。保守停止模式也未解决此问题，没有永久设置该模式。
恢复日志显示 Apple 管理接口已出现，但 MI_00 媒体接口未在观察窗口内就绪；
随后主程序曾无法从 Apple 服务中枚举到设备。该现象的底层原因尚未确定。

Windows pnputil /restart-device 对当前 iPad 的精确实例重启后，Apple 服务重新枚举到设备。
单独重启 Apple 服务未解决。测试结束后已再次成功重启当前 iPad 节点以恢复连接。
本次未修改原生采集程序或 USB 恢复逻辑。尚未验证实际有声听感和长时间稳定性。
